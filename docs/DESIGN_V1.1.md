# V1.1 设计决定

决策日期：2026-10-17。Fable 5.1 通过 Claude Code CLI 读取当前代码与 Paseo SDK 后确定本方案。本版按该方案改进桌面操作和主题一致性。

## 架构

使用 Paseo 原生 React Native 组件构建文件树，通过 RPC 按需读取单层目录。预览仍由本机服务提供，显示在 Paseo 内置浏览器中。嵌入页面移除重复侧栏、品牌区和启动卡片。独立运行保留紧凑文件列表。

面板注册在 `explorer` 和 `workspace` 两个位置。工作区头部按钮及命令入口请求在 `explorer` 打开面板。SDK 类型定义不能证明该位置的实际屏幕布局，需在 Paseo 中人工确认。

## 文件选择与连接

- `preview.open` 创建或复用工作区会话，并同步宿主主题。仅调用该 RPC 不打开浏览器。
- `preview.list` 返回指定目录的文件夹和受支持文件。目录按需读取，保留展开、缓存、选中和滚动位置。
- `preview.select` 校验路径、类型和大小，保存选中文件，再通过 SSE 推送给已连接的预览页。
- 有存活的 SSE 连接时更新原预览页。没有连接时调用 `openBrowser`。再次选择已加载的同一文件不重新解析，文件修改后用“刷新”重读。
- 首次调用 `openBrowser` 后有 10 秒保护期，避免连续点击反复开页。收到已连接状态或打开失败时立即解除保护。期间仍更新最后选中的文件；若立即关闭预览，再点文件可能不会自动重开，用户可点击头部“打开预览”。Fable 5.1 在实现复核中接受了这一边界。
- 页面刷新时恢复会话和选中文件。切换主题时推送新颜色。

文件树桌面行高为 24px，字号为 13px，每级缩进为 14px。头部只保留工作区名、刷新和打开预览按钮。颜色来自 Paseo 的 `theme.colors`。

预览工具栏高 34px，底部状态栏高 22px。Excel 公式栏高 28px，工作表标签移到底部。文档纸面和表格保持白色，周围界面跟随主题。PDF、Word 和 PPT 默认适应可用宽度。Excel 缩放只改变现有网格比例。

Fable 5.1 在最终截图复核中明确：Excel 只有实际 `.sheet-grid` 使用白色纸面；表格以外的空区域使用宿主 `--bg`，滚动条跟随宿主主题。空工作表提示使用 `--muted`。不增加边框、阴影或圆角。

## 公开 API 的限制

`navigation.openBrowser` 返回 `void`。插件无法查询、聚焦、导航或关闭已有浏览器标签页。用户切到其他视图后，选择文件只会更新后台预览。文件树头部保留“打开预览”按钮，供用户手动恢复；是否复用标签页由 Paseo 决定。

SSE 连接用于推断预览页是否存活。它不是宿主提供的标签页关闭事件。

手机端和非 Electron 客户端没有 `openBrowser`，本机服务又只监听 `127.0.0.1`。本版只在这些客户端显示文件树和桌面预览提示。

## 本轮范围

保留现有路径限制、令牌、Host/Origin 校验、只读方法、100 MiB 上限及外部资源限制。保留四种解析器、Word 图片修复、Office ZIP 文件头检查和快速切换时的失效请求处理。

本轮不实现自动链接拦截、手机预览、文件树键盘导航、搜索、文件变化自动刷新、多选和拖拽。不扩展 Excel 图表与条件格式、PDF 连续滚动或复杂 Word 版式。聚焦已有预览标签页需要未来的 Paseo 浏览器 API。

自动检查及尚待人工确认的步骤见 [TESTING.md](TESTING.md)。自动测试通过不代表 Paseo 原生窗口中的操作已经验证。
